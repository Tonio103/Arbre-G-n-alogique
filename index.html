Arbre généalogique

L'arbre ne s'est pas chargé. Cette page est le fichier source : elle doit être construite avant d'être servie. 

npm install
npm run dev      puis ouvrir http://localhost:5173

Pour publier une version en ligne :

npm run build    produit le dossier dist/
npm run preview  sert ce dossier

Sur GitHub : Settings → Pages → Source : GitHub Actions. La publication est automatique à chaque envoi.
